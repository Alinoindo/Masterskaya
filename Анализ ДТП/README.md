# Анализ ДТП по регионам РФ 

Проект по анализу дорожно-транспортных происшествий на основе геоданных (GeoJSON) по регионам РФ.

## Хронологический порядок выполнения скриптов
По ходу выполнения проекта я разделила код на несколько частей, чтобы не перезагружать ядро каждый раз:
1.	`dtp_data_processor.ipynb`
2.	`dtp_data_cleaning.ipynb`
3.	`dtp_clean_eda.ipynb`
4.	`separate_regions.ipynb`
5. Ссылка на дашборд: https://datalens.yandex.cloud/npqucaav57fs8

## Сбор и подготовка данных
Мы получили архивы с GeoJSON-файлами, содержащими геоточки ДТП по каждому региону РФ.
Далее мы написали скрипт для обработки исходных данных:
- Распаковали zip-архивы с GeoJSON-файлами по регионам
- Загрузили GeoJSON-файлы и извлекли данные из `features.properties`
- Объединили данные по всем регионам в единый датасет
- Сохранили результат в файл `dtp_combined.csv`

## Очистка и нормализация данных
После объединения данных был выполнен этап очистки и нормализации:
1. Разделили данные на три таблицы:
- ДТП (`accidents`)
- транспортные средства (`vehicles`)
- участники ДТП (`participants`)
2. Распаковали вложенные структуры (`vehicles`, `participants`) в отдельные таблицы
3. Удалили неинформативные данные
4. Обработали пропуски:
- текстовые поля — заполнены значением `UNKNOWN`
- категориальные признаки — приведены к единому формату
5. Отфильтровали аномальные значения (год выпуска автомобиля)
6. Рассчитали дополнительные признаки (возраст транспортного средства)
7. Сохранили очищенные таблицы:
- `accidents_clean.csv`
- `vehicles_clean.csv`
- `participants_clean.csv`

## Исследовательский и статистический анализ (EDA)
На очищенных данных был проведён исследовательский анализ:
1. Проанализировали распределение ДТП по:
- времени суток,
- дням недели,
- месяцам
2. Извлекли координаты ДТП (latitude / longitude) для геоанализа
3. Исследовали взаимосвязи между:
- количеством участников,
- числом пострадавших и погибших,
- характеристиками транспортных средств
4. Построили корреляционные матрицы
5. Проверили статистические гипотезы о влиянии различных факторов на тяжесть ДТП

## Подготовка данных для BI и визуализации
Для последующей визуализации и дашбордов:
1. Оценили качество данных по регионам
2. Отобрали регионы с наименьшим количеством пропусков
3. Сформировали витрину данных с временными признаками:
- дата, год, месяц, день, час
4. Привели числовые показатели к корректным типам
5. Сохранили итоговый датасет `dtp_top20.csv` для BI-инструментов

## Цель проекта
Выявить факторы, влияющие на аварийность и тяжесть последствий ДТП, и подготовить аналитическую основу для принятия решений по снижению количества и тяжести дорожно-транспортных происшествий.

## Задачи
- Объединить геоданные ДТП по регионам РФ в единый датасет
- Очистить и нормализовать данные
- Провести EDA и статистический анализ
- Выявить ключевые факторы аварийности
